## Setup
To try out this project:
1. Clone the GitHub repository locally to your computer
2. In the command line, type the following: 
  $ npm install nodemon
3. Start the server by typing the following: 
  $ npm run dev
  
## Features
* Search and Browse Music Albums/Tracks: Allow users to search for and browse available albums, tracks, and artists with details.
* Detailed Information for Music: Provide detailed information about each album or track, including artist bio, genre, track list, and duration.
* Music Reviews and Ratings: Allow users to read and leave reviews and ratings for albums or tracks they've listened to, helping others make informed listening decisions.
